How to test · isolation & limitations

Use the existing bottom toolbar: tap Comment, tap a target, write and post a comment, then tap its marker to reply. Try hiding comments, entering and leaving mode, scrolling the spec, scrolling the UI activity panel, and switching deck slides. The yellow test-controls area resets that fixture or simulates send failure.

Save all is simulated. State stays in this browser, separately for each fixture. Nothing is sent to a bot, and this lab has no platform permissions. Viewport controls resize a real iframe; they do not emulate touch, keyboards, or a particular phone browser. Automated touch checks use Chromium device emulation. Physical iOS/Android checks are still needed.

The baseline snapshot is pinned. New library changes can later be served as a candidate against these same fixtures and test scripts.
